# Brand font test fixture

`tests/fixtures/media/brand-sans.woff2` is an unmodified copy of
`assets/fonts/Geist-Variable.woff2` (Geist 1.800, SIL OFL 1.1, © 2023 Vercel, in
collaboration with basement.studio; license text in [`Geist-OFL.txt`](Geist-OFL.txt)).
The `brand-font` fixtures load it under the brand name "Splitly Sans" to test a
storyboard's own `fonts`; it is not a separate typeface.
