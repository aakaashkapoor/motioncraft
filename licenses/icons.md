# Icons: Lucide

`src/icons/nodes.ts` vendors the SVG shapes of 24 icons from Lucide.

- **Source:** https://github.com/lucide-icons/lucide, npm package `lucide@1.53.0`
  (`dist/esm/icons/*.mjs`), copied verbatim. No dependency is added.
- **License:** ISC (Lucide). The icons `check`, `clock`, `code`, `lock`,
  `search`, `terminal` and `arrow-right` derive from Feather (MIT).
- **Author:** Lucide Icons and Contributors; Feather by Cole Bemis.
- **Icons used** (motioncraft name ← Lucide name): chat ← message-circle,
  chart ← chart-column; every other name is the same as in Lucide: terminal,
  code, check, shield, cloud, laptop, box, play, search, file, user, users,
  lock, zap, clock, globe, mail, git-branch, settings, star, arrow-right,
  sparkles.
